# SQL Query Collection

## Project Overview

This repository contains a collection of SQL queries developed as part of a SQL Database Analysis project. The project demonstrates both fundamental and advanced SQL concepts by solving real-world business problems using a sales database. The queries are organized into six checkpoints, each focusing on a different SQL topic.

---

## Database

The project uses a sample sales database containing information about customers, products, orders, employees, suppliers, shippers, and categories. The database was analyzed to answer various business questions through SQL queries.
