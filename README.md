# SQL Query Collection

## Project Overview

This repository contains SQL queries developed as part of a SQL Database Analysis project. The project demonstrates both fundamental and advanced SQL concepts by solving business-oriented problems using the Northwind sample database. The queries are organized into six checkpoints, each covering a different SQL topic.

---

## Database

The project uses the Northwind sample database, which contains information about customers, orders, products, suppliers, employees, shippers, and categories. SQL queries were written to analyze the data and answer different business questions.

## Query Highlights

The SQL queries answer various business questions, including:

- Finding customers with above-average revenue
- Analyzing supplier pricing
- Identifying customers purchasing from the most product categories
- Calculating average order values
- Comparing stock levels across product categories
- Ranking products within categories
- Generating running totals
- Calculating employee average order values
- Measuring the number of days between customer orders

---

## Project Outcome

This project demonstrates practical SQL skills ranging from basic data retrieval to advanced analytical queries. It covers JOINs, aggregation, subqueries, CTEs, window functions, and query optimization concepts while applying them to real business scenarios using the Northwind database.
